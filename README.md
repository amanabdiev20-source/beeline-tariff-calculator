# Калькулятор оптимального тарифа Beeline (ТЗ №2 — Осенний хакатон INAI 2026)

Инструмент для анализа детализации абонента за 3 месяца и подбора самого выгодного тарифа (с учётом комбинаций 0–2 доппакетов, округления звонков до целой минуты вверх, ночного безлимита 01:00–07:00, роуминга и окупаемости стоимости перехода 50 сом).

## Быстрый запуск одной командой

1. Сгенерировать тестовые данные 10 абонентов:
python generate_data.py

2. Запустить расчёт для абонента:
python calculator.py data/usage_1.csv

3. Запустить автотесты (8 граничных сценариев):
pytest

## Что реализовано
- Агрегация потребления по месяцам и округление звонков вверх до целой минуты.
- Учёт ночного безлимитного интернета (01:00–07:00) и отдельной тарификации роуминга.
- Полный перебор комбинаций «тариф + 0–2 доппакета» по средней стоимости за 3 месяца.
- Проверка окупаемости смены тарифа (50 сом) за 3 месяца (иначе вывод «остаться»).
- Набор из 8 модульных тестов (test_calculator.py).
